Cursor，即将彻底消失？-36氪

作者: 新智元 来源: 36kr 快照日期: 2026-08-08

Cursor 这个名字，可能撑不过今年秋天了。

就在刚刚，The Information 独家曝出一个炸裂消息。在 Cursor 周四召开的全体员工大会上，管理层当场交底：SpaceX 对 Cursor 的 600 亿美元收购，最快下周五就能完成。

但更炸裂的还不是时间表。

Cursor 管理层还多说了一句话：Cursor 这个品牌名，将在未来几个月内从新产品上逐步淘汰。

Cursor，那个曾经AI 编程领域最红的独角兽，正在彻底消失。

600亿买的不只是公司，还有名字

600 亿美元。这是有史以来最大的一笔初创公司收购案。

遥想当年，4 个 MIT 学生鼓捣出来的 Cursor，两年干到年入 40 亿美元，财富 500 强里的一大半都是它的客户。

结果现在，直接被马斯克买走。

据曝，交易最迟会在 8 月底落地，具体需要看监管盖章的速度。就在本周，SpaceX 上市后的第一场财报会上，马斯克亲口承认：审批快走完了，「很快」就签。话音刚落，SPCX 股价直接拉了一根大阳线。

Cursor 手里有个还没发布的通用 AI Agent，内部代号叫「Sand」。

按目前的方案，这个产品上线时大概率顶着「Grok Bot」的名字出场。当然，也有可能干脆搞一个全新品牌，连 Grok 也不用。

唯一确定的是，Sand 不会叫 Cursor。

至于很多人每天都在用的那款 Cursor 编程助手，暂时不改名。一位知情人士说，现有工具的名字会先保留。

但更狠的在后面。Cursor 将不会作为独立实体运行！

这是 The Information 报道里最让人震惊的一句话。这家公司会被拆开，分散并入 SpaceXAI 的各个团队。交易一关闭，员工几天之内就要迁进 SpaceX 的 Slack 工作区、运营系统和汇报线。

直接消化掉。

会后的问答环节出现了一幕让人五味杂陈的画面：有员工当场站起来追问，为什么要改成 Grok 品牌？

这个问题之所以扎心，是因为 Cursor CEO Michael Truell 今年早些时候还信誓旦旦地告诉员工，SpaceXAI 把 Cursor 的品牌身份和企业客户关系看作「关键资产」。

几个月过去，「关键资产」变成了「逐步淘汰」。

马斯克为何非买不可？

答案只有五个字：编程他没赢。

Grok 这条线，在企业市场一直打不开局面。截至今年 3 月，Grok 的企业采用率只有 7%。同一时期，Anthropic 的 Claude Code 已经把公司年化收入带到 140 亿美元，编程 Agent 是最大的增长引擎。OpenAI 的 Codex CLI 上线一个月就突破百万开发者。

马斯克的 AI 版图里，编程是唯一一块巨大的空白。

而 Cursor 手上握着 5 万家企业客户、超过百万付费用户，以及开发者每天在真实项目里产生的海量编码数据。事实上，Grok 4.5 已经用 Cursor 的数据做过补充训练，7 月 9 日发布时，编程能力直逼 Claude Opus。

600 亿美元的价格，大部分都看在Cursor的编码数据上。

营收这头的压力也在往上顶。SpaceX 二季度财报刚出炉——营收 78 亿美元，翻了快一倍；光 AI 这块就进账 26 亿，涨了两倍多。听着挺猛？再看支出：一个季度砸了 184 亿搞基建，AI 的服务器和数据中心就烧掉 158 亿，账面上还亏着 5 个多亿。

马斯克在财报会上撂了句狠话：12 月之前，全公司年化收入要摸到 1000 亿。CFO 紧跟着补了句，要达标得靠卖算力的合同加上 Cursor 并表，双管齐下。

开发者那边，是另一种心情

Reddit 的 r/vibecoding 上，有人把这称作「迄今为止最疯狂的 AI 编程操作」。

帖子承认 Cursor 有产品势能，SpaceX 有算力、有分发渠道，也有充足理由追赶 Anthropic 和 OpenAI。这个组合可能很猛。

但 Cursor 一路走到今天，靠的正是快、专注、模型中立。你爱用 Claude 就 Claude，想用 GPT 就 GPT，Cursor 不管。这是大量团队选它而不选 GitHub Copilot 的核心原因。

一旦你的母公司自己就有一个前沿大模型，「我们不在乎你用谁」这句话就再也没法让人真心相信了。

眼下开发者手上什么都不会变。真正的问题在 6 到 12 个月之后，Cursor 还会不会对所有模型一视同仁？还是慢慢变成 SpaceX 技术栈里的一块？

现在看起来，这笔交易让 Cursor 追上 Claude Code 变得越来越渺茫了。

一个时代的收尾

过去两年，AI 应用层最令人兴奋的故事就是 Cursor。

一个 AI 编辑器，四个刚出校门的年轻人。它证明了一件事：不自己训大模型的公司，也能站到牌桌中央。

现在这个故事收尾了。方式是被拆开、被消化、被改名。

下周开发者打开电脑，界面还是那个界面，光标还在那里闪。代码补全该出来的时候照样出来。只是再过几个月，这些东西上面挂的名字，可能就换成了另一个。

600 亿美元买断了一家公司，也买断了 AI 应用层最后一点独立的样子。

模型中立这四个字，还能撑多久？
