GPT Images 2.6 登场，速度质量两不误

按照 OpenAI 的说法，Images 2.6 的图像生成速度较此前提升了 50%，这意味着用户可以在更短时间内拿到结果，也能更高频地调整提示词、反复修改画面。

在 API 端，OpenAI 这次给出了两款定位不同的图像模型。

其中，GPT-Image-2.6 Flare主打速度和日常创作。

在低画质设置下，Flare 最快只需 6 秒就能生成一张图片。除了更快，它还改善了海报、产品展示图等专业视觉内容的布局质量，让模型在处理构图和元素排布时更稳定一些。

另一款GPT-Image-2.6 Sunburst，则更强调画质、细节和多轮编辑中的一致性。

按照 OpenAI 的说法，在中高画质设置下，Sunburst 不仅能提供更好的图像质量，也能在连续修改过程中更稳定地保留人物、产品和品牌细节。

这其实对应的是 AI 生图在实际使用里最常见的痛点。

很多时候，用户不是只生成一张图就结束，而是还要继续改背景、调动作、换文案、替换部分元素。如果模型一改就把人物长相、服装或产品外观一起改掉，那么前面的工作基本就得重来。

Sunburst 想解决的，正是这种只能重画、很难细修的问题。

对于需要制作系列海报、广告素材或品牌视觉内容的团队来说，这种一致性往往比单张图片是否惊艳更重要，因为真正影响工作效率的，从来不是第一稿，而是后面那一连串修改。

这一点，相信每个被折磨到凌晨三点的设计师深有体会。

支持 SVG 导出，AI 修图也有了更多控制选项

除了 GIF，Images 2.6 这次更重要的一层更新，其实发生在编辑和工作流层面。

首先，OpenAI 将此前已经在 ChatGPT 中提供的图像标记功能带到了 API，这意味着开发者和团队可以更明确地告诉模型，到底要改哪一块内容，从而减少本来只想小修一下，结果整张图都被带偏的情况。

同时，Images 2.6 也支持 SVG 导出，方便将生成结果直接应用到网站、App 和印刷等场景中。

OpenAI 还新增了 complexity 参数，允许开发者控制模型在满足请求时投入多少规划工作。按照官方解释，图像质量参数决定的是画面的细节和保真度，而 complexity 决定的则是模型为了满足提示词要求，要在多大程度上进行场景规划和组织。

对于更换背景、调整单个元素这类简单任务，OpenAI 建议使用较低 complexity，以换取更快的编辑速度。对于包含大量元素、复杂关系或严格构图要求的场景，则可以尝试中高 complexity，让模型在理解和组织画面时投入更多处理能力。

在开放范围上，Images 2.6 已于今日面向全球 ChatGPT 和 Codex 用户开放，覆盖所有订阅档位，支持桌面端、移动端和网页端。 开发者则可以通过 API 使用 Flare 和 Sunburst 两款模型。

价格方面，Flare 和 Sunburst 采用相同的 API 定价，与上一代 Images 2.5 保持一致。
