FinalShell 开源了？类 FinalShell 的 SSH 客户端 —— FinallyShell

作者: tonychan 来源: V2EX 快照日期: 2026-11-08

相信这里很多人都用过 FinalShell ，我自己也很喜欢，一直觉得它是最顺手的 ssh 工具。不过现在是 2026 年了，客户端还是 Java 写的，Mac 上的体验也一直挺差...

趁周末 token 重置之前，我用 Opus 5.5 神力对着 FinalShell 复刻了一个出来，换了 go 来写，UI 用的是最近中文推上挺火的 MyGo UI：

项目地址： https://github.com/TooonyChen/finallyshell/

布局基本照着 FinalShell 做的，只不过改了一个左边竖排会话标签出来（我不喜欢横向 tab ）。

老用户打开就能上手。基本功能都齐活了：

- 能直接导入 FinalShell 的连接和分组（密码导不过来，要重新输一遍）
- 终端内核用 Ghostty 的 libghostty-vt ，配色直接用 Ghostty 默认，可以设背景图
- 自带编辑器，有语法高亮、多光标、查找替换，GBK / GB18030 的文件打开不乱码
- 服务器监控：CPU 、内存、负载、网络、延迟、磁盘、进程，两秒刷新一次
- SFTP 拖拽上传，三个任务并发，失败可以重试
- 文件图标支持 VS Code 主题，Material Icon 和 Seti 是内置的
- 密码存在系统钥匙串里，配置文件里没有明文
- 跳板机可以串多层，也支持 SOCKS5 / HTTP 代理
- 端口转发 -L / -R / -D 都有，单独一个 Tunnels 页看状态

欢迎大家来试用以及提 issue ，觉得还行的话求求点个 star 🥹🙏
谢谢～
