Model Context Protocol

What is MCP?

An open standard for connecting AI apps to the tools and data they use. A server says what it can do, the app shows that to the model, and when the model wants something the app calls the server and hands the result back.

Hostthe AI app you use: Claude, Cursor, ChatGPT, an agent Servera small program exposing tools, data or prompts Modeldecides what to use; never talks to a server directly Not RESTJSON-RPC over stdin/stdout or one HTTP endpoint, and servers can talk back Not just JSON-RPCJSON-RPC is the envelope. MCP defines what goes in it: the methods, capability negotiation, transports and auth
