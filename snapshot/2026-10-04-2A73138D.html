IINA 1.5.0 发布了

作者: lhc70000 来源: V2EX 快照日期: 2026-10-04

今天我们发布了 IINA 的 1.5.0 正式版。 如果从我在图书馆中开始写下第一行代码时算起，已经过去十年了。

在将近十年前，我也在 V2EX 发了帖 并得到了很多关注，在此感谢大家一直以来的支持。

IINA 的界面从 0.0.x 时代就没有改变太多，但是随着 macOS 26 的到来，作为「现代 macOS 播放器」的 IINA 也必须更新它的更新设计语言了。 在 1.5.0 中我们第一次大范围重新设计了界面，使得 IINA 在最新的 macOS 中看起来更原生。 我们也同时为旧版本 macOS 做了很多优化，使得新界面也可以兼容旧版本系统的风格。

IINA 1.5.0 最大的更新是可以解锁窗口的长宽比并随意缩放窗口。 这个选项可以在菜单中或者在新的「显示布局」侧边栏中找到。 这个侧边栏同时提供了更多的功能：如果取消「视频铺满窗口」，侧边栏将不会覆盖视频。 如果进一步启用「停靠控制条和标题栏」，标题栏和控制条（如果控制条显示在顶部或底部）也不会覆盖视频，达到类似 VLC 的使用体验。

IINA 1.5.0 支持同时显示左右两边的侧边栏，侧边栏的宽度也可以自由调整。

我们也完全重写了设置窗口。我们希望设置项可以在窗口中一览无余，而不是隐藏在下拉选项、二级菜单或二级页面中。

IINA 1.4.0 引入了插件系统，提供了非常丰富的 API ，包括控制各种播放逻辑， 控制 mpv ，在视频上覆盖显示 WebView ，创建新窗口和在侧边栏中显示自定义界面。 在 1.5.0 中插件侧边栏可以独立固定显示在一侧，大大提升了插件的使用体验。 我们也欢迎大家使用 AI 生成插件解决自己的播放需求，并提交 Pull Request 把自己的插件加入到 IINA 的插件列表中， 让其他用户可以直接在 App 中安装你的插件。

我们也重新设计了官网 iina.io（精力有限，只有英文）。

在技术方面，IINA 1.5.0 最大的变化是摆脱了对 xib 的依赖。 在我刚刚开始开发 IINA 时，作为 Swift 与 macOS 开发的初学者，所有用户界面都根据官方推荐使用了 xib 构建。 现在看来，xib 对协作和版本控制非常不友好，因此 IINA 1.5.0 中大部分的界面已经用纯代码重写。 根据我们已有的 SwiftUI 使用体验，我们觉得 SwiftUI 仍然不够原生、限制过多并且不适合长期维护，所以没有在 IINA 中使用 SwiftUI 的计划； 但是我们的新设置窗口大量使用了 Swift Result Builder 来达到类似 SwiftUI 的开发体验。

维护这样一个开源项目非常消耗精力，我们知道 IINA 仍然有很多不足；比如现在 HDR 和渲染效率方面受到 mpv 的限制仍然存在很多问题。 我们希望在下一个大版本中可以着手解决它们。

欢迎大家通过贡献代码、捐助 等各种方式继续支持 IINA 。谢谢。
