收入增长 45 倍后离开 Anthropic

Cat Wu 在离职声明中讲了个故事。

大约在两年前的时候，Claude Code 是 Anthropic 内部的一个小众实验性的工具。当时 Cat Wu 想试一试这个东西到底可以做些什么，所以让其创建了一个强化学习（RL）环境。

她花了数十个小时，反复向 AI 描述需求、调整方向，却从头到尾没有手动写过一行代码。

结果，Claude Code 真的把任务完成了，这次体验让她深受震撼，最终决定加入 Claude Code 团队。

如今，当初那个不起眼的内部工具，已经成为全球最受关注的 AI 编程产品之一。

Anthropic 在今年 2 月份的时候就透露出消息说，Claude Code 的年化收入运行率已经达到了 25 亿美元，并且比年初翻了一倍多。

根据 11 月 2 日提交的 S-1/A 招股文件，Anthropic 的季度收入从 2025 年第一季度的 3.76 亿美元，增长至 2026 年第三季度的 169.56 亿美元，约为此前的 45 倍。

Cat Wu 并没有在告别信里提到这些数据，而是把更多的篇幅留给产品本身。

用户已经开始让 AI 自主执行大规模代码迁移，甚至从零开发完整产品。从「帮我写几行代码」，到「帮我把整个项目做出来」，开发者与 AI 的关系正在发生变化。

Cat Wu 是这次变革中非常重要的产品负责人之一，但是她不是传统的只做需求文档、制定产品计划的产品经理。

她在 Scale AI 和 Dagster 公司做过的工程技术工作之后就转行到了风险投资领域，在 Index Ventures 工作。2024 年 8 月加入 Anthropic 之后，一开始是研究方向的产品经理，之后慢慢接手了 Claude Code 和 Cowork。

工程师、投资人和产品经理这三个身份在她的身上形成了一个独特的思维方式。

今年 3 月，她在 Anthropic 官方文章中提出，AI 时代的产品经理不能只会写 PRD，还要亲自用 AI 构建原型、设计评测，甚至直接参与开发。从 2024 年起，每次 Claude 发布新的模型时，她都会让其给在线绘图软件 Excalidraw 添加上表格的功能。

在 Lenny's Podcast 中，Cat Wu 提到一些产品的开发周期由原来的 6 到 7 个月缩短到了 1 个月左右，有的甚至只用了 1 天。

她和 ClaudeCode 的创建者 BorisCherny 的合作方式也具有代表性。

Boris 关注的是未来的科技发展路径以及 Claude Code 下一步可以做到的事情。而 Cat Wu 则要将这些想法转化为实际的产品，并且要调动起工程、市场、销售以及财务等部门的力量来完成任务。

她的工作已经由 Claude Code 延伸到了 Cowork 上，并且试着把 AI Agent 的能力扩展到文件处理、资料整理以及更加广泛的知识工作中去。

不过，整篇告别信没有透露她为什么离开，也没有介绍下一站。有人问她是不是准备休息六个月，她只幽默地回了一句：「post agi！」

大意是，等 AGI 实现之后再说。

不到 2 周，3 名重要成员相继离职

如果 Cat Wu 是单独离开，这或许只是硅谷一次普通的职业变动。但把时间线往前拉十天，故事就变得有趣起来。

10 月 24 日，Claude Code 工程师 Thariq Shihipar 在 X 上宣布自己已经离开了 Anthropic。

他说自己在 ClaudeCode 团队里工作了一年多的时间，并且亲眼目睹了产品的规模远远超出最初的预期。

在离别信里他对于 Anthropic 的目标以及同事们给予了很高的评价，说自己曾经和一个很有才华、尽职尽责的一群人一起工作，并打算暂时休息一下之后再开始新的工作。

Thariq 是 Claude Code 在开发者社区里比较活跃的一个工程师，曾经参与过 Skills、上下文工程和 Agent 工作流等一些功能。

有趣的是，在告别帖最后他给用户推荐了一些可以继续关注 Claude Code 产品的账号。

其中包括了 Cat Wu。但是就在他向读者们推荐要继续关注 Cat Wu 的时候，Cat Wu 也离开了 Anthropic。

Cat Wu 的离开还有一段颇为戏剧性的前史，这已经不是她第一次离开 Anthropic。2025 年 7 月，据《The Information》报道，Cat Wu 曾与 Boris Cherny 一起跳槽至 Cursor 背后的 Anysphere。

仅仅约两周后，两人又双双回到了 Anthropic。

10 月 23 日，Claude Code 的重要成员之一 Anthony Morris 也通过 X 平台宣布自己已经离职。

他曾经开发过 Claude Code 的桌面版本，并且认为每个人都有能力用人工智能来创造自己想要的产品，所以一直努力让更多的人去用 Claude Code。

到此为止，Claude Code 的产品负责人、桌面端创建者和一个活跃的工程师在两周内就相继离开了团队。

Anthony Morris 代表的是桌面端产品的工程能力，Thariq Shihipar 参与了 Claude Code 的 Agent 功能以及开发者交互建设，Cat Wu 负责更高层的产品方向以及跨团队的协调工作。

上市前夕，Claude Code 面临新的考验

这一系列人事变动恰好发生在 Anthropic 上市前夕。

对于一家即将进入公开资本市场的 AI 公司来说，明星产品的持续增长和核心团队的稳定性，自然成为投资者关注的焦点。

Anthropic 在招股说明书中也提到了关键人才流失的风险，如果重要的研究人员、工程师或者产品经理离职的话，可能会对公司的研发进度、创新能力以及长久发展造成不利影响。

但是另外一组数据却形成了鲜明的对比。

招股文件显示，Anthropic 员工规模从 2024 年底约 940 人增长至 2026 年 9 月底约 5300 人，而截至 2026 年 9 月底的过去 12 个月，公司整体「遗憾离职率」仅约 1%。这一指标通常指企业希望留住、却主动选择离开的员工占比。

一家人员规模迅速扩张、整体人才流失率较低的公司，为何在短短十多天内，接连失去 Claude Code 三名重要成员。

类似的人事变动，在科技公司上市前后并不少见。

2026 年 8 月， OpenAI 在筹备上市期间，一个月内有多名高级管理人员离开，联合创始人 Greg Brockman 随后更深入地参与公司管理，并推动企业业务团队调整。

企业的从创业阶段发展到上市之后，在组织结构、管理模式以及经营目标上都会发生改变。

和离职的原因相比，更引人关注的是 Claude Code 能否继续保持之前惊人的产品更新速度。

Cat Wu 在 Ars Technica 的采访里提到过，Claude Code 并没有一个明确的长远计划。因为模型的能力变化很快，今天的功能只需要复杂的结构就可以做到，但是几个月之后就只需要依靠模型本身就可以完成了。

这套以模型能力和用户反馈驱动产品迭代的方法，让 Claude Code 能够快速响应开发者需求，但也对团队的判断力和协作能力提出了更高要求。

随着 Anthropic 商业化规模不断扩大，Claude Code 还要兼顾算力成本、服务稳定性、企业权限管理以及数据安全等问题。

随着 AI 降低软件开发和创业门槛，优秀工程师和产品负责人拥有了更多独立创造产品的机会，明星人才的流动或许会更加频繁。
