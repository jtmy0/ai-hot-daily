Advancing Local AI Agents With New Apps, Models and Tools

AI is changing the way people interact with PCs. Agent popularity skyrocketed this year, with projects such as OpenClaw and Hermes topping popularity charts on GitHub. Local large language models (LLMs) surpassed the intelligence threshold to power agents, with models like Qwen 3.8-Flash-Next catching up to frontier cloud models released just a few months ago. As a result, local LLM downloads are already 5x higher than all of last year.

From models to agent harnesses to security to tools, NVIDIA is partnering closely with the local AI ecosystem to make RTX Spark the ideal hardware to run local agents. 

Local AI Agents Made Easy On RTX Spark

From the first boot of RTX Spark, users will be greeted with a “Getting Started” screen to choose and install their agent app.

These agents will come with new, secure sandboxing technology thanks to NVIDIA OpenShell and MXC. MXC delivers operating system-level security, while OpenShell makes it simpler for agents to adopt MXC and adds advanced capabilities such as credential protection and security monitoring. Hermes Agent will integrate granular OpenShell controls and MXC by the end of the month. OpenClaw and GitHub Copilot now support MXC.

After installing an agent, setting up local AI is also now seamless in GitHub Copilot, Hermes Agent, OpenClaw, Perplexity, Pi and WorkBuddy. The apps will recommend an optimized local model and settings configuration for RTX Spark, and set it all up for users in a few clicks.

Many users want the best of both worlds — local models for free iteration, and cloud models for frontier intelligence. NVIDIA Switchyard, an open source model router library, enables agents to intelligently route queries between local and cloud LLMs, allowing the user to minimize cloud usage but still obtain similar results to just running on cloud. Hermes will be adding Switchyard later in October, and other agents like Perplexity Computer and GitHub Copilot have integrated their own routing solutions.

Software providers have made it simple for agents to connect to top Windows apps, with easy-to-use MCP libraries and command line interfaces (CLIs). NVIDIA has also now made available MCPs for its applications, including NVIDIA App, Broadcast, PAIR, Omniverse, RTX Remix and a large library of CUDA-X Skills. 

NVIDIA is also releasing AI playbooks for RTX Spark, available on Friday, Oct 16. Users can set up their first agent, build an AI chief of staff, configure their system for development or design a creative assistant.

Meet Nemotron 3.5 Bolt 74B: Built for Local Agents on RTX Spark

NVIDIA Nemotron 3.5 Bolt 74B-A9B 24GB, available Thursday, Oct. 15, is a new LLM purpose-built for running local agents on RTX Spark. 

This model is a 74B parameter, 9B-active-parameter mixture-of-experts (MoE) model, packed into 24GB using 2-bit quantization with advanced quantization-aware training techniques to retain quality. It aims to achieve the optimal balance between speed and intelligence, being faster than most popular dense models while smarter than most popular MoE models with a similar memory footprint.

Users will be able to run Nemotron 3.5 Bolt 74B at launch through llama.cpp, vLLM, Ollama, Unsloth and LM Studio. It will also be directly accessible via agents such as Hermes and OpenClaw.  

Like other Nemotron models, Bolt 74B is fully open source — including training data, weights and recipes — so developers can fine-tune and customize their own agents.

The Perfect PAIR

Local AI doesn’t have to run on just one PC. NVIDIA PAIR, a personal AI router, is officially moving out of beta today, making it easier to tap into the total AI compute of compatible PCs on a local network. The free, open source software tool automatically discovers and connects devices, installs AI models and inference engines, and distributes AI workloads across available systems.

The official release adds llama.cpp support, direct model downloads from Hugging Face, customizable inference engine settings and RTX Spark support, along with a variety of inference and user experience improvements. 

PAIR works on Windows, Linux and macOS. Developers can contribute to the open source project via Github — just one month after the initial PAIR release, the community has already contributed over 10 features and fixes to the release.

RTX Video Brings Frame Generation and HDR to ComfyUI

ComfyUI is expanding its RTX Video tools with two new nodes: RTX Video Frame Generation and RTX Video HDR. It’s also providing the ability to export EXR files, giving creators more ways to enhance AI-generated video.

RTX Video Frame Generation increases video frame rates for smoother motion for GeForce RTX 40 Series GPUs and newer, while RTX Video HDR converts standard dynamic range (SDR) footage to HDR for greater flexibility in color grading. Combined with RTX Video Super Resolution, these tools enable creators to upscale, enhance and refine video within a single ComfyUI workflow.

For example, creators can combine LTX 2.5 with RTX Video Frame Generation and HDR to transform a 1080p, 30 frames-per-second (fps) SDR clip into a smoother 60 fps HDR video exported as EXR files ready for color grading.
